    How it works

    Load it. Cross over. Land it.

    1. Load

      Drop the folder your agent lives in, a zip, a public GitHub repo or a .barge package. Everything is read inside your browser.

    2. Cross

      Every item is sorted into one plain, versioned .barge package that records where it came from. Secrets are removed before anything moves.

    3. Land

      Pick the new platform. You get a zip laid out for it, a receipt of what changed, and the package to move it again later.

    What travels

    Nothing stays on the dock.

    If the new platform has no equivalent for an item, it rides along inside the package, so nothing is lost.

    Instructions
    Main prompt, rules and scoped rules with their globs.
    Memory
    Saved facts, profiles and daily notes.
    Skills
    Skill folders with their scripts and references.
    Commands
    Slash commands, prompts and workflows.
    Subagents
    Helpers with their own role and tools.
    MCP servers
    Local and remote servers, keys turned into variables.
    Permissions
    Allow, ask and deny rules where the platform supports them.
    Identity
    Name, persona and a stable agent ID.
    Routines
    Heartbeats and scheduled checks, paused until you switch them on.
